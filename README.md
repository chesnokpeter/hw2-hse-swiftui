# ДЗ 2. Список покупок

Чесноков Пётр Ильич, БПИ261

Приложение на SwiftUI. Можно добавить покупку, отметить что уже куплено, найти по названию или категории. Если нажать на покупку, открываются подробности, там можно поменять данные

Сделана основная часть и все 4 допа:

- Фильтр: все покупки, нужно купить, куплено. С поиском тоже работает
- Сортировка по названию, категории и количеству. Сверху ещё написано сколько позиций осталось купить
- Сохранение между запусками. Массив данных кодируется в JSON. Сохраняется после изменения списка, то есть при добавлении, удалении, редактировании и смене статуса. При запуске данные читаются оттуда. Если сохранения пока нет, будут 3 примера из задания
- В форме категории выбираются из списка: продукты, учёба, дом, одежда и другое
